    游戏 agent 的迁移价值，藏在 reset 按钮里

    端到端 VLA 在游戏里成立，靠的是可无限重置的环境而非更聪明的架构。给出一个可跑的动作可逆性审计，用 reset 预算划出端到端的适用边界。

    Agent 的瓶颈不是模型，是输出契约

    换更强的模型对多数 Agent 项目的收益，比把输出契约写死要小；先把结构约束做对，再谈模型升级。
